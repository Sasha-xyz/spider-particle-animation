# 🕷️ Spider Particle Animation

An interactive spider particle animation built using **HTML, CSS, and JavaScript**.

This project explores creative coding and animation using the HTML5 Canvas API. The spider responds to mouse movement while animated particles create a dynamic visual effect against a dark, starry background.

## ✨ Features

- Interactive mouse-following spider
- Animated particle effects
- Starry night background
- Smooth animation using `requestAnimationFrame()`
- Responsive canvas that adjusts to the window size

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas API

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/Sasha-xyz/spider-particle-animation.git
   ```
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Move your mouse around the screen and enjoy the animation!

## 📁 Project Structure

```text
spider-particle-animation/
│
└── index.html
```

## 🎯 Purpose

This project was created as a hands-on learning experience to explore JavaScript, canvas animations, particle effects, and interactive web development.
